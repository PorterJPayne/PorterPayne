Website - Project Motivated Blog

As I study Mechanical Engineering and I begin to work on various projects for school and for my own learning outside of school, I have decided that I am in need of a place to document these things. I have very little previous experience with programming and web design, not to say that I have none, so I figured the first project that could be documented on this site could be the creation of the site itself!

At the beginning of this project, I would have said that I have a general understanding of HTML and CSS and I feel comfortable doing simple projects using them. My knowledge of JavaScript is limited to occasionally being able to understand what simple things like buttons are doing.

My goals for the website are as follows:
- Write every single line of code without the help of AI.
- Create a project portfolio and page for chat/comments.
- Have the site indexed by Google.

I will be hosting the site on github pages because that is what I am familiar with. I will code in html, css, and js.

Current state of the website.

Aug 28, 2026

Here are screen shots of the current state of the website. At the moment, only blogs, projects, and the about page are "functional". This is kinda my minimum viable product. I hope to get the chat, home page, and contact form working in the next week or so. I have been having a lot of fun becoming more familiar with html and css. I have been trying, at each point in the project, to think about what a professional front end developer would do and if I don't know, I just look it up! I have found flex-grow to be a particularly helpful tool to use, I had never heard of it before this week.

One of my main goals for this site has been to use zero AI to help me code and I have held to that. I haven't thought too much about why I feel this way, but I feel that if I were to generate the entire site in one day with ChatGPT, that it would be a waste of my time, EVEN THOUGH it would take much less time. I suppose that it must mean that I place some value on the process and or that learning that I am participating in now. And I must feel that that value is cheapened by having an AI do it for me. Needless to say, I am thoroughly enjoying my time spent on this project. Thanks for reading.
