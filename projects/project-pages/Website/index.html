Website - Project Motivated Blog

As I study Mechanical Engineering and I begin to work on various projects for school and for my own learning outside of school, I have decided that I am in need of a place to document these things. I have very little previous experience with programming and web design, not to say that I have none, so I figured the first project that could be documented on this site could be the creation of the site itself!

At the beginning of this project, I would have said that I have a general understanding of HTML and CSS and I feel comfortable doing simple projects using them. My knowledge of JavaScript is limited to occasionally being able to understand what simple things like buttons are doing.

My goals for the website are as follows:
- Write every single line of code without the help of AI.
- Create a project portfolio and page for chat/comments.
- Have the site indexed by Google.

I will be hosting the site on github pages because that is what I am familiar with. I will code in html, css, and js.
